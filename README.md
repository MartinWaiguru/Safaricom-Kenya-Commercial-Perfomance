# AI Worklog

## Project
Safaricom Commercial Performance Analysis

## Purpose
This document records the use of AI tools during the development of this project. It promotes transparency about AI assistance and distinguishes AI-supported work from my own contributions.

## Chat GPT

AI was used as a learning and development assistant during selected stages of the project. The assistance included:

- Explaining Excel formulas, calculations and data-cleaning concepts.
- Helping me understand Power BI features, DAX measures and visual configuration.
- Troubleshooting technical issues encountered during dashboard development.
- Explaining financial performance concepts, including year-over-year growth and compound annual growth rate (CAGR).
- Reviewing the structure and presentation of the analysis.

## My Contributions

I was responsible for working with the project files, making implementation decisions, configuring the dashboard and reviewing the resulting analysis. I used AI explanations to help me understand technical concepts and resolve problems during development.

## Verification and Quality Control

AI-generated suggestions and explanations were treated as assistance rather than automatically accepted as correct. Calculations, formulas, data transformations and dashboard outputs should be checked against the underlying data and relevant source reports.

Any unresolved issues, assumptions or limitations should be documented in the project README.
